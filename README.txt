PATH//AI — 60 m Reaction + Road-Safe Navigation

Open index.html. The simulation uses a 60 m equivalent detection/diversion envelope. When a vehicle/obstacle enters that envelope or reaches the front perimeter, the planner diverts. The vehicle is constrained to the road surface and every lateral movement is checked before execution. After clearing an obstacle, it returns toward the nearest lane when safe.

Both index.html and index-standalone.html contain the simulation JavaScript inline, so no external JavaScript file is required to run the demo.
